# Linux Server Lab

## 목적
KT NW 인프라운용 직무에 필요한 Linux 서버 운영, 장애 대응, 로그 분석, 백업 자동화 역량을 실습으로 정리하는 저장소입니다.

## 실습 환경
| 항목 | 내용 |
|---|---|
| Host OS | Windows |
| Virtualization | VirtualBox 또는 VMware |
| Server OS | Ubuntu Server |
| Server 1 | linux-web-01 |
| Server 2 | linux-backup-01 |

## 실습 로드맵
1. 실습 환경 준비
2. Linux 기본 명령어
3. 고정 IP 설정
4. SSH Key 접속과 sudo 권한
5. Nginx 웹서버 운영
6. UFW 방화벽 설정
7. 장애 해결 사례 5개
8. cron/rsync 백업 자동화
9. Wireshark 연계 분석

## 최종 목표
Ubuntu Server 2대를 구성하고, SSH/Nginx/UFW 기반 운영 환경에서 장애를 직접 발생시킨 뒤 원인을 분석하고 해결 과정을 문서화합니다.
